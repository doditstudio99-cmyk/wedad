# Dodit Studio — موقع الاستوديو

موقع كامل لاستوديو تصوير الريلز والسمارت بورد: عربي/إنجليزي، حجز مواعيد أونلاين، ولوحة تحكم تعدّل منها كل حاجة.

## المميزات
- **الموقع:** الرئيسية · المجالات (دكاترة/محامين/مدرسين/عقارات) · من نحن · الخدمات والأسعار · معرض الأعمال بفلاتر · آراء العملاء · الحجز · التواصل (واتساب، تليفون، سوشيال، خريطة جوجل).
- **زرار تبديل اللغة** عربي ⇄ English (الموقع بيفتكر اختيار الزائر).
- **الحجز:** العميل يختار الخدمة ← اليوم ← الساعة. المواعيد المحجوزة بتظهر **"محجوز"** ومينفعش تتحجز تاني، والأيام المقفولة مش بتتفتح.
- **لوحة التحكم `/admin`:**
  - الحجوزات: تأكيد / إلغاء / تم التصوير، رسالة واتساب جاهزة للعميل، حجز يدوي أو قفل معاد.
  - مواعيد العمل: الأيام والساعات، مدة المعاد، أيام الإجازة.
  - الخدمات والأسعار، معرض الأعمال (رفع صور وفيديوهات أو لينك ريل)، آراء العملاء.
  - الإعدادات: كل نصوص الموقع، رقم الواتساب، العنوان والخريطة، لينكات السوشيال، تغيير كلمة السر.

## التشغيل على جهازك
```bash
cd website
npm install
ADMIN_PASSWORD=كلمة-سر-قوية npm start
```
افتح `http://localhost:3000` للموقع و`http://localhost:3000/admin` للوحة التحكم.

## الرفع على الإنترنت
الموقع محتاج سيرفر Node.js (عشان الحجز)، ومحتاج **مساحة تخزين دائمة** (Volume/Disk) للحجوزات والصور.

### Render — بضغطة زرار (الأسهل)
[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/doditstudio99-cmyk/wedad)

اضغط الزرار ← سجّل دخول بـ GitHub ← اكتب كلمة سر لوحة التحكم في خانة `ADMIN_PASSWORD` ← **Apply**. الإعدادات كلها جاهزة في `render.yaml`.

### Railway
1. New Project ← Deploy from GitHub ← اختار الريبو ده، وخلي **Root Directory = `website`**.
2. Variables: `ADMIN_PASSWORD` = كلمة السر، و`DATA_DIR` = `/data`.
3. ضيف **Volume** على المسار `/data`.
4. من Settings ← Networking اعمل Domain أو اربط دومين خاص بيك.

### Render
Web Service ← Root Directory `website` ← Build `npm install` ← Start `npm start`، وضيف Disk على `/data` و`DATA_DIR=/data`.

### VPS أو أي سيرفر بـ Docker
```bash
cd website
docker build -t dodit-studio .
docker run -d -p 80:3000 -e ADMIN_PASSWORD=... -v dodit-data:/data dodit-studio
```

## متغيرات البيئة
| المتغير | الوظيفة |
|---|---|
| `ADMIN_PASSWORD` | كلمة سر لوحة التحكم أول مرة (بعدها تقدر تغيرها من الإعدادات). لو مش موجودة بيتعمل باسورد عشوائي ويظهر في الـ logs. |
| `RESET_ADMIN_PASSWORD=true` | لو نسيت كلمة السر: حطها مع `ADMIN_PASSWORD` جديدة واعمل restart، وبعدين شيلها. |
| `DATA_DIR` | مكان حفظ البيانات والصور (الافتراضي `website/data`). |
| `PORT` | البورت (الافتراضي 3000). |

## ملاحظات
- كل البيانات في `DATA_DIR/db.json` والملفات المرفوعة في `DATA_DIR/uploads` — خد منهم نسخة احتياطية من وقت للتاني.
- الأوقات بتوقيت القاهرة (`Africa/Cairo`).
- الأسعار وأرقام التواصل والصور الحالية **مبدئية** — غيرها من لوحة التحكم.
